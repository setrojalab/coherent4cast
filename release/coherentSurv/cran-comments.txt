## Submission summary

New submission of coherentSurv 0.11.0, licensed under GPL-3.
The package fits recurrent/terminal event-history models and returns
joint-law dynamic forecasts, observation-sensitivity bounds, targeting
diagnostics, baseline binary-treatment causal contrasts and validation measures.
Python examples call the same installed R implementation through rpy2 or Rscript.

Maintainer: Sunday A. Adetunji <sundayadetunjisa@gmail.com>
This naming revision supersedes earlier pending development-name submissions
from the same maintainer. Package-specific public operations now use cs_.
Existing calling scripts need the current function names.
