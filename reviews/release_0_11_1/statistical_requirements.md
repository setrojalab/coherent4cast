# Statistical requirements audit for the 0.11.1 candidate

Reviewed 2026-11-26 against the working repository at `D:/Research_Projects/PhD_thesis/COHERENTSURV_RELEASE_2026-11-25/repository`, including the candidate inference safeguards. The source requirement list is the supplied `Pasted text.txt` attachment, sections I.1–10 and IV.1–5. This is an internal software/statistical review, not a journal, regulator, or professional-society endorsement. The attachment is an aspirational checklist; it is not evidence of an official regulatory standard.

“Implemented” means a supported implementation and relevant checks were located, not that arbitrary applications satisfy its assumptions. “Partial” identifies a narrower implementation. “Absent” identifies an unsupported extension. “Claim needs revision” identifies an inaccurate or unjustifiably universal acceptance criterion. ## Generic-contract addendum

The package's `cs_` entry points coexist intentionally with standard S3 generic names. Registration evidence is in [NAMESPACE](../../package/NAMESPACE) and [tools/update-namespace.R](../../package/tools/update-namespace.R).

| Generic group | Audited state |
|---|---|
| `print`, `summary`, `coef`, `vcov`, `predict` | Main likelihood, survival, competing, targeted and causal routes have implemented or inherited methods, with different scientifically appropriate meanings. Targeted/causal coefficients are population targets or contrasts, not intensity regression coefficients. |
| `confint` | A pre-candidate gap allowed `stats::confint.default()` to bypass regularity safeguards. Candidate methods now cover ordinary/survival, competing, targeted and causal fits, honor `parm`/`level`, reject unsupported arguments, preserve existing targeted/causal interval machinery and retain status/scope. See [test-confint-safety.R](../../package/tests/testthat/test-confint-safety.R). |
| `logLik`, `AIC`, `BIC` | Ordinary and competing likelihoods supply `logLik` with parameter count and `nobs`, allowing default AIC/BIC dispatch. No dedicated AIC/BIC method is necessary for that route. Targeted and causal classes intentionally reject `logLik` and hence likelihood information criteria: no single maximized parametric likelihood is supplied ([targeting_continuous.R:295](../../package/R/targeting_continuous.R#L295), [causal.R:279](../../package/R/causal.R#L279)). Arbitrary case weights do not confer ordinary information-criterion calibration. |
| `update`, `residuals`, `model.matrix` | Dedicated fitted-object contracts and tests were not found in the audited namespace/source. Base fallback behavior is not a substitute for a defined refit/reconstruction/residual contract. In particular, an analysis must first specify which residual is scientifically intended for a multitype frailty or targeted model. |
| `tidy`, `glance`, `augment` | Ordinary/competing coefficient tables now preserve inference status. Full ecosystem conformity is incomplete: causal `tidy()` returns `target`, `std_error`, `lower`, `upper` via its contrast table, unlike canonical coefficient-table names; competing `augment()` has no dedicated method. Do not claim blanket broom/gtsummary/modelsummary compatibility without class-specific integration tests. |

## Evidence scope and next work

This audit preserves the distinction between numerical implementation evidence and empirical inference validation. The manuscript still reports transformed-Gaussian simultaneous coverage of 0.5942 at sparse n=250 and 0.9254 at sparse n=1000; the zero-event guard is not a proof that all remaining sparse fits are reliable ([main.tex:479](../../paper/coherentSurv/latex/main.tex#L479)). No new coverage simulation was run for this audit.

Executed checks total 442 passing expectations: 194 across wrapper/validation safety files, 51 in the new `confint` safety file, and 197 across existing continuous-targeting, targeting-integration-boundary and causal files. There were zero failures/warnings, using R-devel, current R sources and the preserved unchanged compiled core. The parent release process must run installation and the complete candidate package checks; these focused results do not substitute for them.

The immediate software repairs are argument/regularity guards and honest output metadata. Delayed entry, longitudinal policies, full latent joint models, smooth baselines, posterior-adaptive quadrature and unrestricted nuisance learners need scoped model specifications, derivations where the estimand/likelihood/EIF changes, independent numerical oracles and a prespecified empirical validation program. None should be represented as implemented by renaming existing functions or broadening a formula parser alone.
