## 1. Domain Mapping: From Clinical Histories to Industrial Reliability

In complex electromechanical systems—such as surgical robots, autonomous vehicles, or grid turbines—units rarely fail without warning. Instead, they accumulate **recurrent non-terminal anomalies** (e.g., calibration drift, actuator overheating) before experiencing an **absorbing terminal failure** (irrecoverable breakdown). 

Furthermore, telemetry logs are frequently **coarsened**: minor faults may only be detected during scheduled diagnostic inspections, creating interval-censored event windows $(L_j, U_j]$ rather than exact timestamps.

`coherentSurv` models this exact process using one retained complete-history probability law:

* **Unit (`id`):** Individual robotic system.
* **Time unit (`time_unit`):** Cumulative operating hours (in thousands).
* **Recurrent marks (`event_types`):** `"calibration_drift"` (Mark 1) and `"actuator_fault"` (Mark 2).
* **Terminal event (`terminal`):** Irrecoverable system failure (`status = 2`).
* **Coarsened observation (`observation = "coarsened"`):** Diagnostic logs rounded or batched into inspection windows.

## 2. Reproducible Synthetic Fleet Generator

We begin by defining a transparent, deterministic data-generating process for $n = 200$ robotic units operating up to $5.0$ thousand hours. Each unit has an unobserved manufacturing/environment frailty $Z_i \sim \text{Gamma}(a, a)$ with variance $\phi = 0.50$, and its terminal failure hazard escalates after experiencing prior actuator faults.

```{r simulator}
sim_robotic_fleet <- function(n = 200, max_hours = 5.0, phi = 0.50,
                                inspection_width = 0.25, seed = 2026) {
  set.seed(seed)
  a <- 1 / phi
  frailty <- rgamma(n, shape = a, rate = a)
  workload <- rnorm(n, mean = 0, sd = 1) # Standardized duty-cycle intensity
  
  records <- vector("list", n)
  
  for (i in seq_len(n)) {
    t_curr <- 0
    n_drift <- 0L
    n_fault <- 0L
    unit_rows <- list()
    row_idx <- 1L
    
    while (t_curr < max_hours) {
      # History-dependent intensities (capped at 2 prior events)
      h_drift <- min(n_drift, 2L)
      h_fault <- min(n_fault, 2L)
      
      lam_1 <- frailty[i] * 0.45 * exp(0.35 * workload[i] + 0.20 * h_drift)
      lam_2 <- frailty[i] * 0.25 * exp(0.50 * workload[i] + 0.30 * h_fault)
      lam_D <- frailty[i] * 0.12 * exp(0.60 * workload[i] + 0.45 * h_fault)
      
      lam_tot <- lam_1 + lam_2 + lam_D
      dt <- rexp(1, rate = lam_tot)
      t_next <- t_curr + dt
      
      if (t_next >= max_hours) {
        # Administrative right censoring at max_hours
        unit_rows[[row_idx]] <- data.frame(
          id = i,
          tstart = t_curr,
          tstop = max_hours,
          lower = max_hours,
          upper = max_hours,
          mark = NA_character_,
          terminal = 0L,
          workload = workload[i]
        )
        break
      }
      
      # Sample event type proportional to cause-specific intensities
      ev <- sample(c("drift", "fault", "terminal"), size = 1,
                   prob = c(lam_1, lam_2, lam_D) / lam_tot)
      
      # Coarsen non-terminal events into scheduled diagnostic inspection windows
      if (ev != "terminal") {
        win_L <- floor(t_next / inspection_width) * inspection_width
        win_U <- min(win_L + inspection_width, max_hours)
        term_flag <- 0L
        mark_val <- if (ev == "drift") "calibration_drift" else "actuator_fault"
        if (ev == "drift") n_drift <- n_drift + 1L else n_fault <- n_fault + 1L
      } else {
        # Terminal breakdown is observed immediately
        win_L <- t_next
        win_U <- t_next
        term_flag <- 1L
        mark_val <- NA_character_
      }
      
      unit_rows[[row_idx]] <- data.frame(
        id = i,
        tstart = t_curr,
        tstop = t_next,
        lower = win_L,
        upper = win_U,
        mark = mark_val,
        terminal = term_flag,
        workload = workload[i]
      )
      
      row_idx <- row_idx + 1L
      t_curr <- t_next
      if (term_flag == 1L) break
    }
    records[[i]] <- do.call(rbind, unit_rows)
  }
  
  out <- do.call(rbind, records)
  rownames(out) <- NULL
  out
}

fleet_data <- sim_robotic_fleet(n = 200, seed = 2026)
head(fleet_data, 8)
```

## 1. Alignment with ICH E9(R1) and Regulatory Workflows

In randomized clinical trials—such as oncology, maternal-fetal medicine, or heart failure—patients frequently experience **recurrent morbidity episodes** (e.g., Grade ≥3 adverse events, disease relapses, or unscheduled hospitalizations) prior to an **absorbing terminal endpoint** (all-cause mortality). 

Under the **ICH E9(R1)** addendum, analyzing recurrent events requires explicitly declaring how terminal events are handled:
*   **While-on-treatment / competing-risk boundary:** Recurrent events cannot occur after death ($Y_{ik}(t) = 0$ for $t > T_i^D$).
*   **Joint complete-history law:** Expected recurrence burden $\mu_k(s, \Delta)$, terminal mortality risk $\pi_D(s, \Delta)$, and Restricted Mean Survival Time (RMST) $r(s, \Delta)$ are evaluated simultaneously from one coherent law.
*   **Causal intervention contrasts:** Standardized arm-specific expectations $\psi_j(a) = \mathbb{E}\{F_j(Y^a)\}$ are estimated via `cs_causal()` with cross-fitted efficient influence functions (EIFs) and explicit separation of prognostic vs. causal assumptions.

## 2. Reproducible Synthetic Trial Generator (CDISC ADaM Conventions)

The generator below simulates $n = 400$ randomized trial participants across two arms (`ARM = 0` control, `ARM = 1` active therapy) over a 2-year follow-up (`AVAL` in years), adhering to CDISC `CNSR` conventions (`CNSR = 0` for observed events, `CNSR = 1` for administrative censoring).

```{r trial_simulator}
sim_clinical_trial <- function(n = 400, max_years = 2.0, phi = 0.40, seed = 1042) {
  set.seed(seed)
  a <- 1 / phi
  frailty <- rgamma(n, shape = a, rate = a)
  
  # Baseline strata and randomized assignment (1:1)
  biomarker_high <- rbinom(n, size = 1, prob = 0.45)
  arm <- rbinom(n, size = 1, prob = 0.50)
  
  records <- vector("list", n)
  
  for (i in seq_len(n)) {
    t_curr <- 0
    n_hosp <- 0L
    n_tox <- 0L
    subj_rows <- list()
    idx <- 1L
    
    while (t_curr < max_years) {
      h_hosp <- min(n_hosp, 2L)
      h_tox <- min(n_tox, 2L)
      
      # Active arm reduces hospitalization & mortality hazards, slightly increases toxicity
      lam_hosp <- frailty[i] * 0.55 * exp(-0.45 * arm[i] + 0.50 * biomarker_high[i] + 0.25 * h_hosp)
      lam_tox  <- frailty[i] * 0.25 * exp( 0.20 * arm[i] + 0.30 * biomarker_high[i] + 0.15 * h_tox)
      lam_dead <- frailty[i] * 0.18 * exp(-0.35 * arm[i] + 0.65 * biomarker_high[i] + 0.35 * h_hosp)
      
      lam_tot <- lam_hosp + lam_tox + lam_dead
      t_next <- t_curr + rexp(1, rate = lam_tot)
      
      if (t_next >= max_years) {
        subj_rows[[idx]] <- data.frame(
          USUBJID = sprintf("SUBJ-%04d", i),
          TSTART = t_curr,
          TSTOP = max_years,
          EVENT_TYPE = NA_character_,
          TERMINAL = 0L,
          CNSR = 1L,
          ARM = arm[i],
          BIOMARKER = biomarker_high[i]
        )
        break
      }
      
      ev <- sample(c("hospitalization", "toxicity", "death"), size = 1,
                   prob = c(lam_hosp, lam_tox, lam_dead) / lam_tot)
      
      is_term <- as.integer(ev == "death")
      mark_val <- if (is_term == 1L) NA_character_ else ev
      if (ev == "hospitalization") n_hosp <- n_hosp + 1L
      if (ev == "toxicity") n_tox <- n_tox + 1L
      
      subj_rows[[idx]] <- data.frame(
        USUBJID = sprintf("SUBJ-%04d", i),
        TSTART = t_curr,
        TSTOP = t_next,
        EVENT_TYPE = mark_val,
        TERMINAL = is_term,
        CNSR = 0L,
        ARM = arm[i],
        BIOMARKER = biomarker_high[i]
      )
      
      idx <- idx + 1L
      t_curr <- t_next
      if (is_term == 1L) break
    }
    records[[i]] <- do.call(rbind, subj_rows)
  }
  
  out <- do.call(rbind, records)
  rownames(out) <- NULL
  out
}
```

## 1. Coherent Event-History Modeling in Credit Risk

In retail and corporate credit portfolios, borrowers rarely transition directly from pristine standing to charge-off. Instead, accounts experience **recurrent distress events**—such as 30-day payment delinquencies or liquidity covenant breaches—that elevate subsequent default hazard before an **absorbing default event**.

Traditional credit models often estimate Probability of Default (PD), Expected Loss / Delinquency Frequency, and Expected Performing Life using separate, incompatible regressions. `coherentSurv` unifies all three under a single complete-history probability law while handling two pervasive banking data challenges:
1.  **Coarsened Reporting Windows:** Corporate financial statements and credit bureau pulls are observed quarterly or monthly $(L_j, U_j]$, creating tied or interval-censored event dates.
2.  **Off-Balance-Sheet / Unreported Distress:** Partial capture of external obligations ($\rho < 1$) requires rigorous sensitivity bounds (`cs_bounds_sparse()`).

## 2. Reproducible Synthetic Credit Portfolio Generator

Below we simulate $n = 300$ corporate credit facilities tracked over $4.0$ years (`time_unit = "years"`), with quarterly financial reporting windows (`quarter_width = 0.25`).

```{r credit_simulator}
sim_credit_portfolio <- function(n = 300, max_years = 4.0, phi = 0.55,
                                 quarter_width = 0.25, seed = 808) {
  set.seed(seed)
  a <- 1 / phi
  frailty <- rgamma(n, shape = a, rate = a) # Unobserved borrower fragility
  leverage_ratio <- rnorm(n, mean = 0, sd = 1) # Standardized baseline debt/EBITDA
  
  records <- vector("list", n)
  
  for (i in seq_len(n)) {
    t_curr <- 0
    n_delinq <- 0L
    n_covenant <- 0L
    acct_rows <- list()
    idx <- 1L
    
    while (t_curr < max_years) {
      h_delinq <- min(n_delinq, 2L)
      h_cov <- min(n_covenant, 2L)
      
      lam_delinq <- frailty[i] * 0.40 * exp(0.45 * leverage_ratio[i] + 0.30 * h_delinq)
      lam_cov    <- frailty[i] * 0.22 * exp(0.35 * leverage_ratio[i] + 0.25 * h_cov)
      lam_def    <- frailty[i] * 0.10 * exp(0.70 * leverage_ratio[i] + 0.50 * h_delinq + 0.40 * h_cov)
      
      lam_tot <- lam_delinq + lam_cov + lam_def
      t_next <- t_curr + rexp(1, rate = lam_tot)
      
      if (t_next >= max_years) {
        acct_rows[[idx]] <- data.frame(
          account_id = sprintf("ACCT-%04d", i),
          win_start = t_curr,
          win_stop = max_years,
          event_mark = NA_character_,
          default_flag = 0L,
          leverage = leverage_ratio[i]
        )
        break
      }
      
      ev <- sample(c("delinquency_30d", "covenant_breach", "default"), size = 1,
                   prob = c(lam_delinq, lam_cov, lam_def) / lam_tot)
      
      if (ev != "default") {
        # Coarsened into quarterly reporting windows
        q_L <- floor(t_next / quarter_width) * quarter_width
        q_U <- min(q_L + quarter_width, max_years)
        def_flag <- 0L
        mark_val <- ev
        if (ev == "delinquency_30d") n_delinq <- n_delinq + 1L else n_covenant <- n_covenant + 1L
      } else {
        # Default date is recorded exactly upon legal notice
        q_L <- t_next
        q_U <- t_next
        def_flag <- 1L
        mark_val <- NA_character_
      }
      
      acct_rows[[idx]] <- data.frame(
        account_id = sprintf("ACCT-%04d", i),
        win_start = q_L,
        win_stop = q_U,
        event_mark = mark_val,
        default_flag = def_flag,
        leverage = leverage_ratio[i]
      )
      
      idx <- idx + 1L
      t_curr <- t_next
      if (def_flag == 1L) break
    }
    records[[i]] <- do.call(rbind, acct_rows)
  }
  
  out <- do.call(rbind, records)
  rownames(out) <- NULL
  out
}

credit_df <- sim_credit_portfolio(n = 300, seed = 808)
```

## 4. Stress-Testing Under Unobserved Credit Events (`cs_bounds_sparse`)

When lenders observe only $\rho = 0.85$ of external credit distress events, `cs_bounds_sparse()` computes exact worst-case and best-case default bounds across large discrete history supports in $O(J + M \log M)$ time using Dinkelbach fractional optimization.

```{r credit_bounds, eval = FALSE}

  recorded_dist = recorded_shares,
  target_vector = default_payoffs,

  recording_fraction = 0.85,
```
