I. Mathematical & Statistical Rigor (The Core Engine)

1. Strict Separation of Uncertainty Layers (No Conflation): Maintain rigid programmatic boundaries between parameter confidence intervals, finite-sample conformal/projection prediction sets, recording-sensitivity identification bounds, and numerical quadrature/series truncation errors. Return each in distinct, strongly typed slots with explicit metadata so analysts cannot misinterpret a numerical tolerance or interquartile range as a frequentist confidence band.
2. Coherent Coarsening & Canonical Legal-Path Fibre Integration: Enforce deterministic canonical ordering (assigning successive occurrences to the available same-mark window with earliest upper endpoint) so overlapping same-mark windows are integrated as a true union without combinatorial permutation double-counting. Never silently jitter zero-length recurrence–death ties.
3. Single Retained Complete-History Law: Generate all downstream targets—terminal risk \(\pi_D(s,\Delta)\), survival \(1-\pi_D(s,\Delta)\), expected type-k burden \(\mu_k(s,\Delta)\), and restricted mean time alive \(r(s,\Delta)\)—from one retained complete-history law. This guarantees mathematical identities (such as \(\pi_D + S = 1\) and stopping event accumulation upon absorption) hold across every horizon.
4. Full Missing-Information Identity (Louis Correction): Always compute observed information under coarsened observations and discrete/quadrature frailty mixing by subtracting the score-variation outer product \(\sum_j w_j (u_j - u_O)(u_j - u_O)^\top\) from the weighted complete-data information \(\sum _{j}w_{j}I_{j}\). Averaging component information alone systematically underestimates standard errors.
5. Automated Regularity & Identifiability Gating: Never treat an optimizer’s zero exit code as proof of a valid statistical fit. Programmatically check gradient infinity norms, observed information matrix rank and positive-definiteness (eigenvalue floor), parameter-boundary contacts, and zero-event cells, withholding standard Wald/Gaussian intervals whenever regularity fails.
6. Non-Nested & Boundary-Aware Frailty Diagnostics: When testing zero frailty variance (φ = 0), enforce the Self–Liang \(\frac{1}{2}\chi^2_0 + \frac{1}{2}\chi^2_1\) boundary reference only when the null fit is regular and interior. When comparing Gamma, Lognormal, and Heckman–Singer discrete mass-point frailties, suppress invalid classical chi-square likelihood-ratio p-values and report descriptive AIC alongside quadrature-refinement convergence deltas.
7. Programmatic Temporal Causality & Zero-Leakage Landmarking: Enforce strict predictability (t-) in cs_build_history() so interval covariates, event counts, and recency indicators are evaluated strictly before the interval's endpoint. Reject pre-landmark forecasts that attempt to condition on post-landmark quadrature fibres or future schedule entries.
8. Exact-Enumeration & Dense Matrix Reference Oracles: Retain independent, unoptimized dense matrix-exponential and exact-enumeration kernels inside the test suite alongside scalable C++17 CSR uniformization and Dinkelbach fractional solvers. Require every release to verify agreement to <10⁻¹² against these analytical oracles.
9. Support for Delayed Entry (Left Truncation) via Conditional Frailty Updating: Upgrade Priority: While v0.11.0 explicitly rejects delayed entry to avoid selection bias on unobserved pre-entry frailty, implement exact left-truncated marginal likelihoods \(L(\theta; \text{history} \mid T_D > L_i, \text{pre-entry eligibility})\) so prevalent cohort studies, registries, and post-landmark clinical trial sub-studies can be modeled natively without dropping late-entering subjects.
10. Non-Selective Inference Guarantees: Prohibit automatic data-dependent switching between asymptotic Gaussian intervals and finite-sample Hoeffding projection envelopes. Require analysts to pre-specify interval = "projection" or interval = "gaussian" uniformly so unconditional or asymptotic coverage guarantees are not invalidated by post-hoc branching.

II. Regulatory & Clinical Readiness (FDA, EMA, MHRA, NHS)

1. 21 CFR Part 11 Cryptographic Audit Manifests: Expand cs_audit_report() so every export bundles SHA-256 fingerprints of serialized R input objects, raw source files, package version, C++17 compiler version/flags, RNG seeds, convergence traces, and explicit assumption flags into an immutable JSON/XML audit artifact.
2. Formal ICH E9(R1) Estimand Pre-Declaration: Embed explicit arguments in cs_fit() and cs_causal() requiring declaration of the target estimand attributes (population, treatment/exposure, variable/endpoint, intercurrent event handling strategy—such as competing risk vs. composite—and population-level summary), printing them verbatim in summary() and cs_audit_report().
3. Self-Contained IQ/OQ/PQ Qualification Utility (cs_validate_env()): Upgrade Priority: Ship a single exported function cs_validate_env() tailored for biopharma Statistical Computing Environments (SCEs) and NHS Trusted Research Environments (TREs). It should execute deterministic Installation Qualification (compiler/BLAS/library checks), Operational Qualification (oracle numerical agreement tests), and Performance Qualification (memory/runtime checks) and emit a signed qualification report.
4. 100% Air-Gapped / Zero-Network Execution: Guarantee that installation from source tarball and all runtime modeling, prediction, sensitivity, and audit functions operate completely offline with zero external network calls, telemetry, or dynamic downloads.
5. Production-Grade CDISC ADaM (ADTTE/ADSL) & OMOP CDM v5.4 Parsers: Upgrade Priority: Elevate the current replication/standards_mapping.R scripts into tested, exported package functions (cs_from_adam(), cs_from_omop()). Enforce strict validation of CDISC CNSR multi-code conventions (never blindly computing 1 - CNSR), PARAMCD filtering, OMOP observation_period containment, and explicit ascertainment provenance.
6. Immutable Locked Model Artifacts for SAPs & SaMD: Separate estimation (cs_fit()) from scoring (predict()) using self-contained, version-tagged serialized objects that store their exact baseline knot grids, covariate scaling metadata, and quadrature rules, preventing silent drift during locked Statistical Analysis Plan (SAP) execution or Software as a Medical Device (SaMD) deployment.
7. Structured Condition Taxonomy (rlang/Base Conditions): Replace generic stop() or warning() strings with typed S3 condition classes (cs_error_temporal_leakage, cs_warning_nonregular_fit, cs_error_budget_exceeded) so automated regulatory pipelines and targets/drake workflows can programmatically catch, classify, and log anomalies.

III. C++17 & Cross-Language Software Architecture

1. Header-Clean, R-Agnostic C++17 Core: Keep inst/include/coherentSurv/ completely free of R.h, Rinternals.h, and Rcpp.h. Isolate all SEXP marshalling inside thin src/rcpp_*.cpp translation units so the C++17 numerical engine can be compiled directly into standalone C++ clinical binaries or native Python extensions.
2. Native C-API / pybind11 Python Bindings (Beyond rpy2 Subprocesses): Upgrade Priority: While v0.11.0 supports Python via rpy2 and Rscript, build a lightweight native Python wheel (pybind11 or nanobind) directly over the R-agnostic C++17 headers. This eliminates R runtime overhead in Python production pipelines and enables native scikit-learn / lifelines interoperability.
3. Minimalist Hard Dependency Footprint: Keep Imports restricted to base packages (stats, utils, methods, Matrix, survival) and Rcpp. Keep ggplot2, jsonlite, broom, and testthat strictly in Suggests so enterprise and CRAN environments never break due to upstream tidyverse changes.
4. Bit-for-Bit Cross-Platform Determinism: Guarantee identical floating-point outputs across Linux, macOS (x86_64 and ARM64), and Windows (UCRT/MSVC) by enforcing deterministic parallel reduction trees, explicit Xoshiro256++ PRNG streams for importance sampling and Monte Carlo covariate draws, and avoiding platform-dependent -ffast-math compiler flags.
5. Memory-Bounded Compressed Sparse Row (CSR) Propagation: Store transition generators Q in CSR format and propagate row vectors and cumulative rewards without materializing dense S × S matrix exponentials. Enforce explicit memory and uniformization term/chunk budgets that fail loudly with structured errors rather than exhausting server RAM.
6. Zero-Copy Memory Views on Large Cohorts: Pass large interval-history design matrices and covariate arrays from R to C++17 via read-only pointer views (const double*, const int*) to keep peak memory under 1 GB even on 250,000+ subject cohorts.
7. Graceful OpenMP Parallelization: Parallelize independent subject likelihoods, EIF evaluations, and Monte Carlo trajectory draws across OpenMP threads while strictly honoring OMP_NUM_THREADS, user n_threads arguments, and CRAN's 2-core check cap, compiling cleanly when OpenMP is absent.
8. Numerical Overflow/Underflow Guards: Standardize log-sum-exp evaluation for coarsened path mixtures, scaled uniformization series with explicit geometric tail truncation bounds, and recurrence-stabilized log-Gamma evaluations near φ → 0.
